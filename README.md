# auto-clicker-95

auto-clicker-95 is a lightweight and efficient autoclicker built with Lua, designed to streamline repetitive clicking tasks on your desktop applications. With its intuitive configuration, you can automate clicks with precision and speed, enhancing your productivity without sacrificing performance.

## Features

- **Customizable Click Rates**: Set the frequency of clicks to meet your specific needs, allowing for both rapid clicks and slower paced interactions.
- **Hotkey Support**: Start and stop the autoclicker using user-defined keyboard shortcuts for quick access without disrupting your workflow.
- **Cross-Platform Compatibility**: Works seamlessly on various operating systems, making it versatile for users regardless of their environment.
- **User-Friendly Interface**: Designed with simplicity in mind, it allows users to configure settings easily without requiring extensive technical knowledge.

## Installation

To install auto-clicker-95, ensure you have Lua installed on your machine. Then, clone this repository and run the installation script:

```bash
git clone https://github.com/Developer/auto-clicker-95.git
cd auto-clicker-95
lua install.lua
```

## Basic Usage

After installation is complete, you can launch the autoclicker by running the following command in your terminal:

```bash
lua autoclicker.lua
```

Once the program is running, you can set your desired click rate and assign a hotkey to toggle the autoclicker on or off. For example, use the hotkey `F1` to start clicking and `F2` to stop.
